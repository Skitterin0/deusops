# Лабораторная работа №3

## Цель работы

Поднять приложение на Django, используя Nginx для обработки статических файлов и прокси, используя роли. Научиться шаблонизации конфигураций.

## Задачи

1. Поднять Vagrant-окружение с помощью Vagrantfile
2. Написать роль для установки Nginx, добавить её в requirements.yml
3. Подготовить шаблоны конфигурационных файлов для Nginx
4. Настроить проксирование запросов в контейнер с Django
5. Написать плейбук для установки Nginx и Docker на соответствующие группы хостов
6. Запустить приложение на хостах группы app

## Структура проекта
```
lab3/
├── host_vars/           # Переменные для отдельных хостов
├── group_vars/          # Переменные для групп хостов
├── roles/               # Локальные роли
│   └── nginx/           # Роль для Nginx
│       ├── defaults/    # Переменные по умолчанию
│       ├── templates/   # Шаблоны конфигураций
│       ├── tasks/       # Задачи роли
│       └── meta/        # Метаданные роли
├── inventory.ini        # Инвентарь с хостами
├── playbook.yml         # Основной плейбук
├── requirements.yml     # Файл зависимостей ролей
├── Vagrantfile          # Настройка виртуальных машин
└── README.md            # Этот файл
```

## Использование

### Установка и запуск

1. Запустите виртуальные машины:
```bash
vagrant up
```

2. Установите роли из репозиториев:
```bash
ansible-galaxy install -r requirements.yml
```

3. Запустите плейбук:
```bash
ansible-playbook -i inventory.ini playbook.yml
```

### Проверка работоспособности

1. Проверьте статус Nginx:
```bash
ansible -i inventory.ini web -m shell -a "systemctl status nginx"
```

2. Проверьте статус Docker-контейнеров:
```bash
ansible -i inventory.ini app -m shell -a "docker ps"
```

3. Откройте веб-приложение в браузере:
- Сервер 1: http://192.168.56.201
- Сервер 2: http://192.168.56.202
